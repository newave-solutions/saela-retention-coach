# Retention Coach AI

Create a chat app, not chat, a conversation app that is going to be acting like a customer calling into a customer service, um, department, um, with an wanting to cancel because of, uh, specific things like in this case, it's going to be, uh, pest control related. So it's gonna be, uh, maybe a switchover, maybe affordability, maybe, um, persistent activity, maybe a poor experience, maybe, um, they have a agreement dispute, maybe they have, um, uh, issue with the product, concerns about the product, and similar. I want this app to be able to be as realistic as possible and easy for the end user to navigate. The end user will be a customer experience agent who is going to be either in retention... Yes, who's gonna be in, uh, retention training. So the AI needs to be able to learn from the live conversation and adapt its method or strategy accordingly so that as to, um, make it maybe to where if the secret, like the underlying motive behind the cancellation is actually addressed by the agent during the chat, during the conversation, um, then make it to where it's negotiable, maybe even savable from cancellation. So, um, after that, um, only at that, you know, you might make it at a, um, m- medium diff, uh, advanced kind of level that is difficult. Just the right amount of difficult, but not too easy at all. I'd rather it be more difficult than easy, but make it realistic. It will be a two-way conversation. Dialogue will be happening between the agent and the AI.
